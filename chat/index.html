GitHub 토큰 연결

대화는 비공개 저장소 konghwanhee/Agent의 chat/messages.json에 쌓입니다. 이 브라우저에서 읽고 쓰려면 토큰이 한 번 필요합니다.

  1. Fine-grained token 만들기
  2. Repository access → Only select repositories
    konghwanhee/Agent 하나만 고르기
  3. Permissions → Contents: Read and write
    나머지 권한은 그대로 두기

토큰은 이 기기의 브라우저(localStorage)에만 저장되고, 저장소나 다른 곳에는 남지 않습니다. 공용 기기에서는 쓰고 나서 로그아웃해 주세요.
